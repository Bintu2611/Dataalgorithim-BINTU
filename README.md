# Mathematical Expression Evaluator Using Stacks

## 1. Project Overview

The Mathematical Expression Evaluator is a Python-based program that evaluates mathematical expressions using the stack data structure. It processes expressions from an input file, performs calculations according to operator precedence and parentheses, and saves the results to an output file.

The project demonstrates the practical application of stacks, functions, operator precedence, file handling, exception handling, and type annotations in Python.

## 2. Project Objectives

The main objectives of this project are to:

- Implement a stack data structure using Python.
- Evaluate mathematical expressions using two stacks.
- Apply operator precedence when performing calculations.
- Handle expressions containing parentheses.
- Read mathematical expressions from an input file.
- Write calculated results to an output file.
- Handle invalid operators, invalid tokens, and division by zero.
- Apply Python type hints and modular programming techniques.

## 3. Technologies Used

The project uses the following technologies and programming concepts:

- **Programming Language:** Python 3
- **Data Structure:** Stack
- **Built-in Modules:** `operator`
- **Type Annotations:** `typing`
- **File Handling:** Reading from and writing to text files
- **Error Handling:** `try`, `except`, `ValueError`, and `IndexError`

No external Python packages are required.

## 4. Project Features

### Stack Implementation

The program defines a `Stack` class with the following methods:

- `push(item)` – Adds an item to the top of the stack.
- `pop()` – Removes and returns the top item.
- `peek()` – Returns the top item without removing it.
- `is_empty()` – Checks whether the stack contains any items.
- `size()` – Returns the number of items in the stack.

### Mathematical Operations

The program supports four basic arithmetic operations:

| Operator | Operation |
|---|---|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |

Multiplication and division have higher precedence than addition and subtraction.

### Parentheses Support

The evaluator processes expressions inside parentheses before applying operations outside them.

### File Processing

The program reads expressions from `input.txt` and saves the corresponding answers to `output.txt`.

It ignores blank lines and separator lines containing five hyphens (`-----`) in the input file.

### Error Handling

The program includes checks for:

- Removing an item from an empty stack.
- Viewing an empty stack.
- Using an unsupported mathematical operator.
- Dividing by zero.
- Encountering invalid expression tokens.
- Detecting certain invalid mathematical expressions.

## 9. How the Program Works

The program follows these steps:

1. The `main()` function reads expressions from `input.txt`.
2. Each expression is split into tokens.
3. Numbers are stored in a number stack.
4. Mathematical operators are stored in an operator stack.
5. Operator precedence determines the order of calculations.
6. Parentheses control which calculations are performed first.
7. The `calculate()` function performs each arithmetic operation.
8. The final result for each expression is collected.
9. The `write_results()` function saves the answers to `output.txt`.
10. A confirmation message is displayed when processing completes successfully.

## 10. Data Structures and Algorithms

The project uses the **Last In, First Out (LIFO)** principle.

This means the last item added to a stack is the first item removed.

Two stacks are used:

- **Number stack:** Stores numbers and intermediate calculation results.
- **Operator stack:** Stores mathematical operators and opening parentheses.

The evaluator processes operators according to their precedence. When an operator with lower or equal precedence is encountered, pending operations are performed before the new operator is pushed onto the operator stack, except when an opening parenthesis is encountered.

This approach allows the program to evaluate supported mathematical expressions without relying on Python's `eval()` function.

## 11. Limitations

The current version has several limitations:

- It supports only addition, subtraction, multiplication, and division.
- Input expressions must contain spaces between tokens.
- Decimal numbers are not recognized as valid number tokens.
- Unary negative numbers are not fully supported.
- Parentheses must be correctly matched.
- Some malformed expressions may produce stack errors rather than a clear validation message.
- If one expression raises an exception, the current program does not continue processing the remaining expressions.
- The program uses text files rather than a graphical interface or database.
